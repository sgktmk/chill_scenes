# 深夜のコンビニ (Convenience Store) — Scene Spec

## 概要

- シーン名（日本語 / 英語）: 深夜のコンビニ / Convenience Store
- 雰囲気・コンセプト: 深夜、郊外の道路沿いに佇む「Chill Mart」。店内の灯りだけが
  暖かく、駐車場は静か。ときどき客がひとり、自動ドアから出入りする。
- 解像度: 320×240（元画像 1448×1086 を変換、32色）
- 昼夜サイクル: なし（固定時間帯: 深夜）

## 画像ファイル

- `base.png` — 構図の元画像（提供された Chill Mart の夜景）
- `pixel-data.js` — `node tools/png2pixel.mjs base.png -w 320 -h 240` の出力
  （`CHILL_MART_IMG`、シーンHTMLにインライン展開済み）
- `preview.png` — 変換結果のレンダリングプレビュー
- 空の扱い: 画像の空をそのまま使う（固定夜空。動的な空バンドは無し）

## 動き

- 店頭のエプロン（`FEET_Y≈173`）を客がひとり歩いて登場 → 自動ドア中央
  （`DOOR_X≈180`）で入店（ドアへ吸い込まれるようにフェード） → 数秒後に再び
  出てきて画面端へ去る。画面上には常にひとりだけ。深夜なので出入りの間隔は長め。
- 客は手描きスプライト（2フレームの脚アニメ、進行方向で左右反転）。水平位置は
  経過時間の関数（フレーム落ちに強い）。
- 空にごく控えめな星の瞬き（CSS）を少量重ねて生気を出す。

## 音

- ベース環境音: 遠くの街のローランブル（ローパスしたブラウンノイズ）＋
  冷蔵ケース／自販機／蛍光灯の電気ハム（60/100/200Hz のサイン）。
- 時々鳴る音: まばらな虫（コオロギ）、たまに通り過ぎる車（バンドパスノイズの
  スウェル＋接近→遠ざかりのフィルタスイープ）。
- 客ごとの音: 脚の動きに同期した控えめな足音、自動ドアのスライド音（バンドパス
  スイープ＋末尾の「コトッ」）、入店音「ピンポーン」。入店・退店時にまとめて鳴らす。
- こだわり: あくまで引きの視点。イベント音は減衰＋ローパスした「遠く」バスを
  通して、駐車場の向こうで鳴っている距離感を保つ（大きくしすぎない）。
