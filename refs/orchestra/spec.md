# Orchestra（オーケストラ） — Scene Spec

## 概要

- シーン名（日本語 / 英語）: オーケストラ / Orchestra
- 雰囲気・コンセプト: 開演前のコンサートホール。オーケストラがチューニング中。
  **開放弦 A** を中心に、D・E・G・C などの音が高低さまざまに重なって鳴る。
  奏者は弓を動かし、トロンボーンはスライドを、打楽器はマレットを動かす
- 解像度: 160×144（元画像がゲームボーイ解像度 10:9 のドット絵）
- 昼夜サイクル: なし（固定: 屋内・開演前）

## 画像ファイル

- `base.png` — 構図の元画像（160×144、16色）。元は 1322×1190 の
  アップスケール済みレンダー。1ピクセル = 8.26px の格子だったので、
  ネイティブ解像度 160×144 に戻したものを base.png としている
- `bg.png` — 奏者を全員取り除いた背景（ステージ、ハープ、ティンパニ、
  大太鼓、譜面台は据え置き）
- `parts/NN-<name>.png` — 奏者 28 人（各 1 枚）
- `parts/NN-<name>_bow.png` — 弦楽器奏者の弓 11 本（本体側からは弓を
  消してある＝弓が動いても奏者の胴体が見える）
- `parts/NN-<name>_{slide,mallets,beater,hand}.png` — 可動部 5 枚
  （トロンボーン 2 本のスライド、ティンパニのマレット、大太鼓のビーター、
  ハープを弾く手）。座標指定で切り出す（`split.mjs` の `subs`）
- 空の扱い: 屋内なので空なし（透過なし・全面不透明）
- パーツ・背景は `split.mjs` で base から機械生成している:

  ```bash
  node refs/orchestra/split.mjs <source.png> refs/orchestra /tmp/viz.png
  ```

  顔（明るい楕円）を種として図形領域を測地距離で分割し、奏者ごとの
  シルエットを切り出す。弓は「顔以外の明るい細長い連結成分」として
  検出し、本体側は周囲の色で埋める。背景の穴は同じ行の最も近い
  非穴ピクセルで埋める（ステージが横縞構造のため）

## 動くパーツ（レイヤー）

| パーツ | 状態 | 動き方 |
|---|---|---|
| `<name>_bow`（11本） | — | 弓。演奏中は弓の軸方向に最大±2px スライド（ボウイング） |
| `wind5_slide` / `wind6_slide` | — | **トロンボーンのスライド**（ベルから左下へ伸びる管＋先端のノブ）。演奏中、ベルから遠ざかる向き（左下）へ 0〜2px 抜き差しする |
| `timpanist_mallets` | — | マレット。打つたびに上げ→下ろし→戻り（音は下ろした瞬間に鳴る） |
| `bassdrum_beater` | — | 大太鼓のビーター。ヘッドの方向（左）へ振る |
| `harpist_hand` | — | ハープを弾く手。1音ごとに弦から 1px はじく |
| 奏者 28 体 | — | **動かさない**（`?pose=lift` の切り出し確認用にだけ移動する） |

- **奏者本体の全体揺れはしない。** 図形を丸ごと平行移動させると椅子ごと
  ずれて見えて不自然なので、奏者は base.png の位置に据え置き、
  動きは弓・スライド・マレット・手といった「切り出した可動部」だけが持つ
  （＝弓が主役）
- 弓の軸方向はランタイムで各弓スプライトの主成分から求める
- トロンボーンはベルを正面に向けて描かれている: 胸元の**金色の輪がベル**、
  その右上へ伸びる管も固定。動くのは**輪から左下へ伸びる点線状の管と
  先端のノブ**＝スライド。細い斜めの点線で手やあごに接しているため、
  座標を直接列挙して切り出す（split.mjs の `subs.pixels`）。管の下端は
  隣の奏者や背景に取られていたので、列挙したピクセルは所有権を奪って
  切り出す
- 木管列 wind1〜wind4 はサックス系（曲管）でスライドが無いので動かさない
- 1ストロークは弓の長さの大半を使う（5〜8px の弓に対して最大±2px。
  それ以上動かすと弓が腕から離れて見える）。弓速はほぼ一定なので、
  ストロークが長いほど周期は遅い（0.5〜1.0Hz 程度）
- 弦楽器奏者は休みを短くして常に 4〜8 本の弓が動いている状態を保つ

## 動き（パーツ以外）

- **チューニングの波**: 常時 8〜10 人ほどが同時に鳴らしている。奏者ごとに
  「弾く 2.5〜7秒 → 休む」を繰り返す（弦は 2〜9秒、トロンボーンは 4〜14秒、
  ティンパニ・ハープは 6〜18秒、その他の木管は 8〜34秒）。ティンパニと
  ハープは 1回の演奏中に 0.5〜1.5秒おきに繰り返し打つ／弾く。
  40〜80秒に一度、ほぼ全員が同時に A を出す「トゥッティ」の山が来て、
  また散っていく
- **基準 A**: 開始直後とその後 30〜60 秒おきに、オーボエ役が長く澄んだ
  A4（440Hz）を出す。そのとき他の奏者は少し多めに反応する
- 音と絵は同じステートマシンで駆動する（鳴っている奏者＝弓が動いている奏者）
- デバッグ: `?at=<秒>`（その時刻まで早送りして静止）、
  `?pose=bow`（弓・スライド・マレットを可動域いっぱいで固定）、
  `?pose=lift`（全奏者を上へ大きくずらして背景の抜けを確認）、
  `?pose=home`（全員静止）、`?a=1`（基準Aを即発音）

## 音

- ベース環境音: ホールの空気（ごく小さいフィルタードノイズ）、低い部屋鳴り。
  すべてプロシージャル生成の残響（ノイズ・インパルス応答の ConvolverNode）を通す
- チューニング音（主役）:
  - 弓の音 = 微妙にデチューンした鋸波 2 本 + サブサイン → ローパス。
    立ち上がり 0.1〜0.3 秒、弓圧のゆらぎあり。開放弦なのでビブラートなし
  - ピッチ: ヴァイオリン G3/D4/A4/E5、ヴィオラ C3/G3/D4/A4、
    チェロ C2/G2/D3/A3、コントラバス E1/A1/D2/G2、木管・金管は A4 中心。
    **A が最頻**（約半分）。±4〜15セントのずれでうなりが出る
  - ときどき隣り合う開放弦を同時に鳴らす（5度の重音: A+D, A+E, G+D）
  - オーボエの基準 A は帯域通過させたリード系の音色で長め
  - 奏者のステージ上の x 座標に応じてステレオ定位する
- 打楽器・ハープ: ティンパニの弱打（音程あり、A1中心）、大太鼓のごく弱い
  一打、ハープのつま弾き。打撃音はマレット／ビーターが下りきる瞬間
  （0.2秒後）に鳴らす
- 時々鳴る音: 椅子のきしみ、譜めくり、遠くの咳（数十秒に一度）
- 昼夜での変化: なし
